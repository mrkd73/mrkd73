چت اکشن‌محور وردپرس با حس تلگرام + دستیار زنده شناور + GapGPT.

== Description ==

Agent WP یک افزونهٔ مدیریتی است که:

* چت ادمین شبیه تلگرام
* Tool layer با لاگ و rollback
* کلید API فقط روی سرور
* دستیار زنده با اسکن و پیشنهاد
* خواندن/نوشتن کد قالب و افزونه با تأیید و نقطه بازگشت

== Installation ==

1. پوشه `agent-wp` را در `wp-content/plugins` قرار دهید.
2. افزونه را فعال کنید.
3. به منوی «ایجنت وردپرس» بروید و کلید GapGPT را ذخیره کنید.
