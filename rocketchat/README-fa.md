# پیام‌رسان — فقط روی سیستم خودت (اوبونتو)

این پروژه برای **کلود / تونل / دامنه عمومی** تنظیم نشده.
همه‌چیز باید روی همان کامپیوتر خودت اجرا شود و در مرورگر همان سیستم باز شود.

## آدرس‌ها

| سرویس | آدرس |
|--------|------|
| پیام‌رسان (مرورگر) | `http://localhost:3000` |
| API ورود موبایل | `http://127.0.0.1:3001` |
| کد تست OTP | `1234` |

## نصب یک‌باره

```bash
cd rocketchat
bash install-on-ubuntu.sh
```

اگر برای اولین بار Rocket.Chat ویزارد ادمین می‌آورد، یک ادمین بساز، بعد:

```bash
export RC_ADMIN_USER='نام‌کاربری-ادمین'
export RC_ADMIN_PASS='رمز-ادمین'
bash scripts/start-stack.sh
```

اگر از قبل ادمین داری، همان را در `export` بگذار و `start-stack.sh` را بزن.

## هر بار روشن کردن

```bash
cd rocketchat
bash scripts/start-stack.sh
```

بعد **روی همان سیستم** برو به:

`http://localhost:3000`

از گوشی/سیستم دیگر با `localhost` باز نمی‌شود.

## فلوی ورود

1. شماره موبایل (مثل `0912xxxxxxx`)
2. کد `1234`
3. اگر جدید: نام → نام‌خانوادگی → عکس (اختیاری) → یوزرنیم → رمز
4. اگر قبلی: ورود با کد `1234` یا با رمز

کاربر در پنل ادمین Rocket.Chat ذخیره می‌شود.

## اگر صفحه ورود موبایل نیامد

1. مطمئن شو API روشن است: `curl http://127.0.0.1:3001/tg-auth/health`
2. دوباره UI را تزریق کن:
   ```bash
   TG_AUTH_BASE=http://127.0.0.1:3001 node scripts/deploy-auth-ui.js
   sudo docker restart rocketchat-app
   ```
3. در مرورگر Cache را خالی کن یا Incognito باز کن
4. فقط `http://localhost:3000` را باز کن (نه IP کلود، نه دامنه تونل)
